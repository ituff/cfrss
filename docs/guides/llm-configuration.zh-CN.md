# 配置 LLM

文章总结、全文翻译和每日摘要都会调用一个 **OpenAI 兼容的 chat-completions
接口**。CFRSS 本身不带模型 —— 服务商由你自己指定，密钥也始终在你自己手里。

如果你完全跳过这一步，CFRSS 依然可用，只是没有总结、翻译和每日摘要。

---

## 1. 添加服务商

**设置 → AI 服务商 → 添加**，填四个字段：

| 字段 | 填什么 |
| --- | --- |
| **名称** | 便于识别的名字，比如 `DeepSeek` |
| **Base URL** | 接口根地址，**需要带 `/v1` 的要带上** |
| **模型** | 准确的模型 id |
| **API Key** | 服务商给的密钥 |

CFRSS 实际请求的是 `{Base URL}/chat/completions`，并带上
`Authorization: Bearer {API Key}`。只要这一点对，其他都好办。

### 可用的 Base URL 示例

| 服务商 | Base URL | 模型示例 |
| --- | --- | --- |
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini` |
| DeepSeek | `https://api.deepseek.com/v1` | `deepseek-chat` |
| 月之暗面 Kimi | `https://api.moonshot.cn/v1` | `moonshot-v1-8k` |
| 智谱 GLM | `https://open.bigmodel.cn/api/paas/v4` | `glm-4-flash` |
| 硅基流动 | `https://api.siliconflow.cn/v1` | `Qwen/Qwen2.5-7B-Instruct` |
| OpenRouter | `https://openrouter.ai/api/v1` | `openai/gpt-4o-mini` |

> 以上只是举例，不是推荐 —— 请以服务商文档里当前的 Base URL 和模型名为准。
> 只要兼容 OpenAI chat-completions 接口，都能用。

⚠️ **接口必须能从公网访问。** 请求是由你的 Cloudflare Worker 发出的，不是从你
本机发出的，所以跑在 `http://localhost:11434` 上的模型（Ollama、LM Studio 等）
除非做了隧道或公网映射，否则连不上。

## 2. 分配功能

仍在 **设置 → AI 服务商** 里，指定每个功能用哪个服务商：

| 功能 | 用在哪里 |
| --- | --- |
| **总结** | 文章工具栏上的 ✦ 按钮 |
| **翻译** | 🌐 按钮，以及每日摘要 |

两个功能可以指向同一个服务商，也可以用便宜快的模型做总结、用更强的做翻译。
最多可以存 **10** 个服务商。

## 3. 测试

每个服务商那一行都有 **测试** 按钮，会发一个小请求，并告诉你接口、密钥、模型名
是否都对。先去点它，再去找别处的问题。

---

## 会发送什么

点「总结」时，CFRSS 会把**文章全文**（去掉标签后的纯文本）和一段「生成简短结构化
摘要」的指令一起发给你的服务商。翻译则是把文章的 HTML 和一段「只译文字、保留所有
标签」的指令一起发出去。

请求统一带 `enable_thinking: false`，避免推理模型在回答前先花掉一堆 token；语言
跟随你的**界面语言** —— 中文界面要到的就是中文摘要。

**你不按按钮，就不会有任何数据发出去。** 不存在后台自动摘要。

## 缓存

| 结果 | 存在哪 | 什么时候失效 |
| --- | --- | --- |
| 总结 | 按文章 | 不失效，除非手动清除 |
| 翻译 | 按文章 **加** 目标语言 | 不失效 |
| 每日摘要 | 按自然日 | 手动重新生成 |

缓存让第二次打开是瞬时的，也正因为如此，同一篇文章换一种目标语言翻译会再花一次
调用。

## 翻译语言

支持 10 种目标语言：中文 · English · 日本語 · 한국어 · Français · Deutsch ·
Español · Русский · Português · Italiano。

工具栏上可以循环切换三种显示方式：

- **双行对照**（默认）—— 每段原文下面跟译文
- **左右并排** —— 两栏
- **只看译文**

目标语言和显示方式都按设备记忆。

## 密钥存在哪

API Key 会先用 `ENCRYPTION_KEY` 加密再写进数据库，接口也不会以明文返回 ——
设置页上永远只显示掩码。

也就是说：**一旦更换 `ENCRYPTION_KEY`，所有已保存的密钥都会失效**，只能重新填。

## 排查

| 现象 | 可能原因 |
| --- | --- |
| 测试立刻返回 4xx | Base URL 或模型名不对。先确认服务商是否需要 `/v1`。 |
| 测试返回 401 / 403 | 密钥错误，或该密钥没有这个模型的权限。 |
| 测试卡住然后超时 | 接口从 Cloudflare 网络访问不到。 |
| 总结能用，翻译不行 | 两个功能分配给了不同服务商，两个都要检查。 |
| 提示「最多 10 个 LLM 配置」 | 先删掉不用的服务商。 |
